# Contacter le support de Vestia

Dernière mise à jour : 16 novembre 2026

Ce document est traduit en plusieurs langues. En cas de différence entre les versions, la version française fait foi.

## Nous écrire

Écrivez-nous à : **contactervestia@gmail.com**

Pour que nous puissions vous aider rapidement, indiquez si possible :

- l'adresse email de votre compte Vestia ;
- le modèle de votre téléphone et la version de l'application (Profil, Aide et légal, Version) ;
- une description du problème, avec une capture d'écran si elle peut aider.

## Délai de réponse

Nous répondons en général sous 3 jours ouvrés. Ce délai est indicatif.

Pour les demandes concernant vos données personnelles (accès, rectification, suppression, opposition), nous répondons dans un délai d'un mois au plus, comme le prévoit le RGPD.

## Langues

Nous répondons en français et en anglais. Vos messages sont acceptés dans toutes les langues.

## Avant de nous écrire

- Télécharger vos données : Profil, Mes données, « Télécharger mes données ».
- Supprimer votre compte : Profil, « Supprimer mon compte ».
- Lire la Politique de confidentialité et les Conditions d'utilisation : Profil, Aide et légal.
